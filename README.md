# Wandering Wings

🐦‍⬛🐦🦅🦆🕊️🐧🦢🦃🦉🐓🦚🦤🦜🪿

**WORK IN PROGRESS**

Interactive web app visualizing global bird migration. With animated hexagon maps, real GPS tracks, and species stories. Built with eBird and Movebank data.

Bird data provided by [eBird](https://ebird.org) and the Cornell Lab of Ornithology.
